# 教学书种子变更日志

[`chapterSeedLog.ts`](../../src/main/database/chapterSeedLog.ts)，该文件只保留当前版本与上一版摘要。

## 维护规则

- **改教学书前先查历史**：调整 `seedGuideBook/` 或 `entitySeed.ts` 时，先在本目录检索相关版本，
  确认既有文案的改动原因与影响范围。
- **升版本时写摘要**：提升 `CHAPTER_SEED_VERSION` 后，在 `chapterSeedLog.ts` 追加一条摘要；
  该文件出现第 3 条时，把最旧一条迁到本目录对应区间。
- **区间优先续写**：新版本属于哪个区间就追加到对应文件；单文件接近 500 行时按版本另拆文件，
  并更新上表与相邻文件的区间链接。
- **只搬运不改写**：拆出 / 迁入只移动文字，不改历史结论；条目里的旧实现描述是当时事实，
  与当前代码冲突时以代码为准。
