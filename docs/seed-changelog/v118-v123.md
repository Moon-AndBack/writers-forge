## v123 · 回收站列表 + 详情批

章节 / 大纲 / 伏笔 / 灵感四个回收站由单列列表升级为**左侧列表 +
右侧只读详情**——章节回收站可看章名、状态、字数、原卷、删除时间与按段落渲染的只读正文，
原卷也在回收站时给出提示；大纲回收站条目可看名称、字数、原归属、删除时间与只读富文本正文，
卷 / 分组看类型、条目数与删除时间；伏笔回收站可看标题、派生状态、描述富文本、正文 / 大纲 /
回收三处锚点原文摘录、回收备注与时间戳；灵感回收站可看标题、标签、完整正文与时间戳。
行点击 / Enter / 空格选中，行尾还原 / 彻底删除不触发选中；条目被还原、彻底删除或清空后
详情自动回落到「选择左侧条目查看详情」，回收站为空时保留原整块空态。纯渲染层改动：
数据层 / IPC / 表结构均未变。教学文案同步（卷二「回收站」章补「点开条目看详情」、卷三新增

键提升让老库也能看到新文案。

## v121 · 右栏剧情筛选语义修正批

章节 / 大纲模块右栏「剧情」页签的**时间线下拉移除
「全部时间线」**，改为在当前时间线内单选——默认跟随全局当前选中时间线，其次回退首条；
时间线为空时显示占位与空态。该下拉**只筛选本页签**，不切换全局当前时间线、不写
`timeline:active`；`ALL_VALUE` 更名为 `ALL_LINES_VALUE`，只留给剧情线使用。剧情线选择升级为
`{ timelineId, value }` 并与选择时的时间线绑定：在右栏切换时间线时由受控 `onChange` 同步
重置为「全部剧情线」，跟随全局时间线切换时也直接回「全部」，不再静默回退到意外线。
「全部剧情线」由扁平列表改为**按绝对年份分组**（复用 `groupScenesByYear`：同年一排、
未定年沉底），每张卡经新增共享 `PlotSceneHeading` 标出来源剧情线名称与线色；单条剧情线
保持逐场景一行（时间列 + `timeDesc`），无视觉回归；`TimelineView` 与右栏共用该标题组件。
纯渲染层改动：数据层 / IPC / 表结构均未变。教学文案同步（卷二「章节页的左右两栏」、卷三
「右栏：剧情 / 伏笔 / 灵感（只读）」、大纲「条目、分组与卷」「每场景一行与右栏正文编辑」、
卷四「右栏面板」「剧情时间轴与主时间线」：时间线单选无「全部」、只筛右栏、全线按年
分组并标来源线、单线逐场景、切换时间线重置剧情线选择），键提升让老库也能看到新文案。

## v120 · 违禁词交互重做批

状态栏计数改为**常显**——命中 > 0 为红色胶囊，点击向上展开
「本章命中清单」（按 `word + category` 聚合：词 + 类别 + 次数，标题「本章命中 N 处，
涉及 M 个词」，底部「打开违禁词库」；Esc / 点外部 / 打开词库时收起，命中清零或切章
自动收起）；0 处渲染灰色静态 `span`，不可点击、不进 Tab 序列。计数与清单下沉到
`CleanWordHitsPill`，快照由新增 `proofreadHits.ts` 以 `useSyncExternalStore` 发布
（`{ total, groups }`，单 owner、签名去抖），`useChapterStatusBar` 只渲染节点，避免
计数变化重注册状态栏插槽。词库弹窗重排为**三行**：筛选（来源 全部 / 内置 / 我的 +
类别六项 + 搜索）→ 结果（计数 + 词表 + 内置词表出处）→ 添加（类别 + 内容 + 「添加」）；
**批量粘贴导入移除**（`cleanWordsImport.ts` 删除），改为弹窗底部逐条添加，校验与右键
菜单一致（trim 非空、无换行、2–100 字，非法时按钮禁用并给行内提示）；正文右键
「加入违禁词库」保留，与添加行共用 `addCleanWords`（重复词更新类别并提示「词条已存在，
已更新类别」）。新增违禁词标记悬停浮层（`useCleanWordHover`：词 + 「类型：类别」，与伏笔
同属一条锚点链时伏笔浮层优先）。教学文案同步（卷五「违禁词检测」章：状态栏计数与命中
清单、词库弹窗三行布局、词表来源；卷二「违禁词提示」节；大纲「违禁词检测」条目），
键提升让老库也能看到新文案。

## v119 · 未知模型默认窗口 1M 批

未知模型的默认上下文窗口由 32K 改为 **1M**——
两处 `DEFAULT_CONTEXT_WINDOW`（渲染层 `ai/contextBudget.ts` 与主进程 `ai/modelMatch.ts`）
均改为 `1_048_576`。这是「未知模型」的**乐观默认值**（目录与内置基线都匹配不到时才生效）：
代价是中转站的小窗口模型不会被提前压缩，超限请求会在上游被拒；用户仍可在设置页
「AI 助手 → 自定义上下文窗口」为具体模型手填窗口（优先级高于目录 / 基线）。i18n 的
`panel.context.unknownModel` 本就是 `{{tokens}}` 插值，经 `formatTokenCount` 自动显示
「1M」，无需改 key；教学文案同步（设置「上下文占用与自动压缩」、大纲「AI 写作助手」、
大纲「上下文压缩与模型窗口」三处：32K → 1M，并补默认值的代价与覆盖方式）。

## v118 · AI 快捷功能「重写本段」批

右栏 AI 快捷功能「改写」重命名为「重写本段」
（内部 key 仍为 `rewrite`，只改 i18n 显示文案）。`functions.ts` 的 rewrite system prompt
重写，与「润色」划清界限：明确要求句子层面明显不同（不得复用原句结构、不得只替换
同义词），并允许重排段落与叙述顺序、增删修饰与调整详略（篇幅可明显增减）；保留
「不得改变事实、人物关系与情节走向」的安全边界，把「保持原人称 / 视角 / 语气」降为
默认，新增优先级条款——【补充要求】指定人称、视角、语气或改写方向时以其为准。
教学文案同步（卷二、卷三右栏、卷四「右栏面板」三处 AI 功能列表移除实际不存在的
「自定义」项，改写更名为「重写本段」并补充与「润色」的区别）。
